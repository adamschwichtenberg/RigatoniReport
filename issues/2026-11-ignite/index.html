Copilot & AI · Spotlight

Two to know

Why it matters: Two platform moves that are new to most customers, and both are generally available now.

GA · Copilot Managed Runtime

One place to run what people build

Your people will build apps and agents in Copilot Code, Cowork and Copilot Studio. Copilot Managed Runtime is where those apps live: Microsoft hosts, runs and governs them, separate from where they were made.

  • GA: host, run and govern apps from Copilot Code, Cowork, Copilot Studio and compatible third-party tools in one Microsoft-managed environment.
  • New: an optional Microsoft Fabric backend gives apps a database, storage and data APIs out of the box.
  • Governed like Microsoft 365: published Copilot Code apps keep your identity, security and governance controls, and appear in the Microsoft 365 admin center.
  • Announced, Agents and Workflows: build Copilot Studio agents and workflows locally in your own dev tool, keep versions in GitHub, and publish with the command line.
Build anywhereCopilot Code, Cowork, Copilot Studio or a third-party tool.
Run in one placeOne runtime and admin view; usage shows in Agent 365 Cost Management.

Read: Managed Runtime blog · Book of News

GA · Microsoft IQ

Your organization's intelligence, in every agent

With Microsoft as your AI provider, Microsoft IQ brings together the context you already have, so every app and agent starts from what your organization knows.

  • Work IQ: how your people work, from email, meetings, chats and files, plus the context behind decisions.
  • Fabric IQ: your business data with trusted metrics and their meaning. Foundry IQ: your documents and other unstructured content. Web IQ: real-world information.
  • Reuse what works: plugins, skills, tools and agents are GA; business plugins (Frontier) package expert guidance for higher-quality results and lower token costs.
  • GA: context works across Microsoft Copilot, GitHub Copilot, Microsoft Foundry and any agent harness through MCP.
Less integration workBuilt on products you already use, with no new SKU or subscription.
Less to governWorks with Agent 365; business plugins carry sensitivity labels and change auditing.

Security · Center stage

Center stage: Microsoft Perception

~80%of alerts in a typical Defender queue are now covered by the Triage Agent, plus AWS and Salesforce alerts.
GA · was Project Perception

Security agents that work your queue

Microsoft Perception is now generally available. Specialized agents handle common security work, and playbooks you approve tie them together.

  • Three teams of agents, GA: red team agents find weaknesses like an attacker, blue team agents triage and investigate, green team agents prioritize fixes.
  • Preview: the Web App Pen Test Agent tests your web apps for exploitable weaknesses, with evidence and fix guidance.
  • Agentic risk prioritization: the Posture Prioritization Agent focuses teams on critical exposures; in preview, the Risk Reduction Agent recommends patching through Intune or shielding.
  • Preview: MAI-Cyber-2-Flash, Microsoft's purpose-built security model, available only in Codename MDASH.

Three moves for this quarter

Rigatoni's read of the Ignite security news.

Find every agent first

Use Agent 365 to find local and shadow agents, then watch Dynamic Agent Risk as it comes online. Inventory before you govern.

Give agents their own identity

Use Entra Agent ID so Conditional Access applies to agents, not borrowed user accounts. Restrict the agent, not the person.

Let agents take the first pass in the SOC

Pilot the Perception Triage Agent, and plan how you will approve vulnerability shielding. People approve high-impact actions.

Also worth knowing

New MAI models GA

MAI-Code-2 for demanding agentic coding and MAI-Code-2-Flash for everyday coding, both GA in GitHub. MAI-Image-2.7 and 2.7-Flash (preview) keep images on-brand.

Microsoft-Decision-1.1 GA

A fast, low-cost model for routing and classification, now with image input. It decides whether Copilot or Cowork handles a request. Preview: Microsoft-Retriever-1 for faster grounding.

Agents browse in governed Edge Preview

Require Microsoft and third-party agents to browse in Edge for Business, each in its own window with its own Entra agent identity.

Keep unapproved agents off company data Preview

Intune marks devices running unapproved agents noncompliant, and Conditional Access blocks them from company data.
