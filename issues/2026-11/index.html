04 · Security for AI

Govern, protect, operate

Why it matters: Microsoft's security story for AI rests on three pillars: govern every agent, protect what agents can do, and run security operations as one system.

Govern · Agent 365

Agent 365: one control plane for every agent

  • 50M+ agents now registered; Microsoft named a Leader in the 2026 Gartner Magic Quadrant for AI Agent Management Platforms.
  • New Action Center: clean up inactive agents, reassign ownerless ones, block risky ones automatically.
  • Admin tip: set who creates agents in Entra ID › User settings.

Read: Security blog, Nov 3 · Message Center MC1506733

Protect · Project Perception

Project Perception: protection that adapts to each agent

  • Now extended to agents inside the enterprise, with Guardian Agents watching what agents do.
  • Dynamic Permissions scope an agent's authority to its current task; access narrows or asks for approval as risk changes.
  • GA: Defender discovers 50+ local AI agents on Windows and macOS; Execution Containers contain them on Windows.

Read: Security blog, Oct 19 · What's new, Nov 5

Operate · ISOC

ISOC: one security operations centre in Microsoft Defender

  • Preview: XDR, SIEM, threat intelligence and automation in one place in Microsoft Defender.
  • Included for eligible Defender Suite, Microsoft 365 E5 and E7 customers.
  • From November 15, 2026, included retention grows from 30 to 90 days.

Read: Defender XDR blog · Security blog, Sep 23

More ways to secure AI

  1. One data loss prevention (DLP) policy for Chat and Cowork Rolling out Purview can block labeled content, sensitive prompts and sensitive web searches across Chat and Cowork.
  2. Stop prompt injection on local AI agents Preview Defender runtime protection inspects prompts, tool calls and tool responses, and can block an action before it runs. Start in audit mode, then block.
  3. Conditional Access templates for agents Entra Agent ID Ready-made policies block high-risk agent identities and set rules for autonomous and on-behalf-of agents.
  4. No more orphaned agents Entra Agent ID Sponsor lifecycle workflows notify managers and transfer an agent's sponsorship automatically when its sponsor changes roles or leaves.
  5. Admins approve new agent identities Rolling out Agent blueprints now need admin consent before they can create agent identities, for tighter control and auditability.
  6. Guide: Don't Leave AI Exposed Microsoft's practical guide to agent inventory, ownership, access, monitoring and runtime protection.

CISO notes

Talking points from Mikhail Falkovich, Customer Security Officer, Microsoft

Identity is the connective tissue of attacks

Device-code phishing, adversary-in-the-middle, token theft and OAuth abuse turn one compromised identity into cloud access and persistence.

Do: Move to phishing-resistant sign-in (passkeys), restrict device-code flow with Conditional Access, and govern OAuth apps.

AI speeds attackers up, and is now a target

Attackers use AI to raise tempo and scale, and go after AI systems through prompt injection and stolen AI credentials and secrets.

Do: Prioritise AI-enhanced signal correlation, automatic attack disruption and posture management for AI, and protect AI credentials and secrets.

Treat cyber risk as a board-level business risk

The new Microsoft Digital Defense Report 2026 urges leadership-level governance, identity defence at every layer, and continuous exposure management.

Do: Read the report and bring its top recommendations to your next risk committee.
