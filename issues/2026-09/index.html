CISO notes

Talking points from Mikhail Falkovich, Customer Security Officer, Microsoft

Make phishing-resistant sign-in the default.

AI-enabled phishing bypasses passwords, SMS and voice codes. Microsoft begins making passkeys the default in Entra ID (public cloud) on September 1, 2026. Entra passkey update

Do: Plan the move to passkeys, starting with admins and privileged users, and enforce it with Conditional Access.

Assume sign-in tokens can be stolen.

Device-code phishing and OAuth abuse steal tokens, even when multifactor authentication (MFA) is on. Device-code phishing

Do: Block device-code flow where it isn't needed and require compliant devices; keep Continuous Access Evaluation on.

Treat your build pipeline as attack surface.

Attackers target open-source packages and build systems to steal developer and cloud credentials. ChainDrop supply-chain worm

Do: Use trusted feeds, pin dependencies, protect publishing credentials and be ready to rotate secrets.

Go deeper: Microsoft Security Blog
