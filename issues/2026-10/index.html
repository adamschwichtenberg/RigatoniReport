04 · Security for AI

Govern, protect, operate

Why it matters: Microsoft's security story for AI rests on three pillars: govern every agent, protect what agents can do, and run security operations as one system.

Govern · Agent 365

Agent 365: govern agents and their tools

  • AI mode finds ownerless or inactive agents when you ask in plain language (preview).
  • Agent Management Rules block agents or reject publish requests automatically (preview).
  • Tools management (GA): allow or block Model Context Protocol (MCP) servers, plugins, skills and connectors.

Read: Agent 365 blog, Sep 30

Protect · Project Perception

Project Perception: AI agents that defend

  • New in September: ISOC became the shared foundation that Perception agents work on.
  • Agents investigate and respond alongside analysts, with people in control.
  • In public preview since August 3, 2026.

Read: Security blog, Sep 23 · Official Microsoft Blog, Jul 27

Operate · ISOC

ISOC: one security operations centre in Defender

  • Preview: security information and event management (SIEM) and extended detection and response (XDR) in one place.
  • Cases and workbooks, plus playbooks generated from plain language.
  • From November 15, 2026, included retention grows from 30 to 90 days. Eligible: Defender Suite, Microsoft 365 E5 or E7 without an active Sentinel workspace.

Read: Defender XDR blog · ISOC overview

More ways to secure AI

  1. Keep sensitive data out of shadow AI GA Purview data loss prevention (DLP), enforced by Entra Global Secure Access, blocks uploads to unsanctioned AI tools, for people and agents.
  2. Conditional Access for agents Preview Updated guidance (Sep 30) to allow only approved agents and block high-risk agent identities; start in report-only mode.
  3. Archive stale content out of Copilot Rolling out Archive inactive SharePoint content so Copilot stops using it; retention and holds still apply.
  4. eDiscovery for Copilot Pages and Notebooks Rolling out Search, hold and export AI-created content without hunting for container URLs.
  5. Label at enterprise scale Rolling out Auto-labeling simulations now cover up to 20 million items and 50,000 sites.
  6. Your DLP already covers Cowork Rolling out Existing Copilot DLP policies apply to Cowork automatically, with no new setup (Message Center MC1477182).

CISO notes

Talking points from Mikhail Falkovich, Customer Security Officer, Microsoft

Make MFA phishing-resistant, admins first.

Adversary-in-the-middle phishing steals passwords, MFA codes and session cookies.

Do: Give privileged users passkeys or Windows Hello first, add risk-based Conditional Access, and revoke sessions on suspected theft.

Close exposure before attackers find it.

Attackers favour exposed apps, trusted third parties and misconfigured SaaS over new exploits.

Do: Harden internet-facing assets, patch faster, and audit anonymous or overly broad access in low-code sites.

Build ransomware resilience.

Ransomware groups combine data theft, encryption and disruption, often after stealing privileged credentials.

Do: Turn on attack surface reduction rules, tighten privileged access, and keep tested, isolated, immutable backups.
